Common HTTP methods
GET – Retrieve data.
POST – Send data to the server.
PUT – Update existing data.
DELETE – Remove data.
PATCH – Partially update data.

HTTP status codes
200 OK – Request succeeded.
301 Moved Permanently – Resource has moved.
404 Not Found – The requested page doesn't exist.
500 Internal Server Error – The server encountered an error.

HTTP vs. HTTPS
HTTP sends data in plain text and is not encrypted.
HTTPS (Hypertext Transfer Protocol Secure) encrypts the communication using TLS/SSL, making it much more secure. Modern websites almost always use HTTPS to protect passwords, payment information, and other sensitive data.
