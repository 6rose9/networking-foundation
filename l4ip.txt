# Binary

#255 (255 = 11111111)

positive is 1 , negative is 0

255 - 128 = 127 -> 1
128 - 64  = 63  -> 1
63  - 32  = 31  -> 1
31  - 16  = 15  -> 1
15  - 8   = 7   -> 1
7   - 4   = 3   -> 1
3   - 2   = 1   -> 1
1   - 1   = 0   -> 1

# 192
192 - 128 = 64  -> 1
64  - 64  = 0   -> 1
0   - 32  = -32 -> 0
0   - 16  = -16 -> 0
0   - 8   = -8  -> 0
0   - 4   = -4  -> 0
0   - 2   = -2  -> 0
0   - 1   = -1  -> 0

=> Subnet Mask

It's can define which are network and which are Host.

eg. 
IP Address : 192.168.1.10
Subnet Mask : 255.255.255.0

Binary
255          255           255           0
1111111      11111111      11111111      00000000

1 bit = Network
0 bit = Host bits

CIDR Prefix /24
Classless Inter-Domain Routing Notation

/24 = 11111111.11111111.11111111
/30 = 11111111.11111111.11111111.111111 -> 2 only Devices
